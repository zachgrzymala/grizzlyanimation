# grizzlyanimation.com

Portfolio site for **Zach Grzymala** — 3D animator & character artist.
Static HTML/CSS/JS. No framework, no build step required to deploy, no monthly fee.

Replaces the old Adobe Portfolio site.

---

## Deploy: order of operations

**Do these in order.** Nothing goes dark if you follow the sequence — the old site keeps
serving until the new one is confirmed live.

### 1. Put the site on GitHub

```bash
git init
git add .
git commit -m "New portfolio site"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/grizzlyanimation.git
git push -u origin main
```

> The repo **must** be public for GitHub Pages on a free account.

### 2. Turn on Pages

Repo → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch `main`, folder `/ (root)` → **Save**.

Wait ~2 minutes, then confirm it works at `https://YOUR-USERNAME.github.io/grizzlyanimation/`.

**Do not touch DNS until that URL loads correctly.**

### 3. Point the domain (Namecheap)

Your domain is registered at **Namecheap** — *not* Adobe — so cancelling Adobe cannot
affect it. Domain is paid through **2027-02-10**.

Namecheap → **Domain List** → `grizzlyanimation.com` → **Manage** → **Advanced DNS**.

Delete the existing `A Record` pointing at `151.101.x.x` (that's Adobe's edge), then add:

| Type | Host | Value | TTL |
|---|---|---|---|
| A | `@` | `185.199.108.153` | Automatic |
| A | `@` | `185.199.109.153` | Automatic |
| A | `@` | `185.199.110.153` | Automatic |
| A | `@` | `185.199.111.153` | Automatic |
| CNAME | `www` | `YOUR-USERNAME.github.io.` | Automatic |

Leave any MX/email records alone.

### 4. Attach the domain in GitHub

Settings → Pages → **Custom domain** → `grizzlyanimation.com` → Save.
A `CNAME` file is already in this repo, so this should populate on its own.

Once the DNS check passes (can take 15 min – 24 h), tick **Enforce HTTPS**.

### 5. Only now, cancel Adobe Portfolio

Confirm `https://grizzlyanimation.com` loads the new site with a valid padlock **first**.
Then cancel the Adobe subscription.

## What changed from the old site

- All **78 images** were pulled off Adobe's CDN at full resolution before cancellation
  (they stop being served once the subscription ends) and converted to WebP.
  **89 MB → 20 MB**, initial page load ~2 MB.
- Videos still stream from your existing **Vimeo** and **YouTube** accounts — unaffected by Adobe.
- Players load **on click**, not on page load. The old site mounted 23 iframes at once on
  the Rebound page; this one mounts zero until you ask for one.
- Bio and section copy rewritten from student framing to working-professional framing.
- Contact form replaced with direct email + social links.

### Navigating the site

- **Split heroes.** Every project page puts its main player, headline and spec slate in one
  screen — no scrolling to reach the thing the page is about.
- **Sticky jump bar** on Rebound, Character Modeling, Story and About. Jumps to any section
  in one click and tracks which section you're in. Falls back to native anchor jumps
  (with correct offsets) if JavaScript fails.
- **Keyboard:** press `g` then `h` home · `r` reel · `b` rebound · `m` modeling · `d` disney
  · `s` story · `a` about. In the lightbox: `←` `→` to move, `Esc` to close.
- **Scroll progress** bar across the top of every page.

## Editing the site

### Text, layout, copy
Everything is generated by `tools/build.py`. Edit it, then:

```bash
python tools/build.py
```

That rewrites the eight HTML pages. Commit and push; Pages redeploys automatically.

### Adding new work

1. Drop full-res images in `_masters/`.
2. Add entries to `tools/manifest.json` (`{"t":"img","uid":"<filename-without-extension>","cap":"Caption"}`
   or `{"t":"vimeo","id":"<video-id>","h":"<hash-if-unlisted>"}`).
3. Regenerate derivatives and metadata, then rebuild:

```bash
python tools/optimize_images.py
python tools/fetch_video_meta.py
python tools/build.py
```

### Updating your resume
Replace `assets/docs/zach-grzymala-resume.png` and
`_masters/c6f0054c-5b89-4128-88e0-ac348a527f59.png`, then run `python tools/optimize_images.py && python tools/build.py`.
A PDF would be better than a PNG for recruiters — drop one in `assets/docs/` and change the
download link in `build_about()`.

### Local preview

```bash
python -m http.server 8912
```

Then open `http://localhost:8912`.

## Design notes

**Brand.** **Grizzly Animation Studios** appears in the nav, the page title and the footer.
The hero headline is a logline instead, with *Zach Grzymala* on a blue rule beneath it.

To change the logline, edit `LOGLINE` near the top of `tools/build.py` and rebuild — it is a
two-part tuple, one line each:

```python
LOGLINE = ("Personality,", "frame by frame.")
```

**Palette** sampled from the original splatter logo: `#1984FF` bright, `#1C5FAC` deep, on
`#08090B`. Filled buttons deliberately use the deeper blue — white on `#1984FF` is only
3.63:1 and fails WCAG AA; white on `#1C5FAC` is 6.40:1.

**Type.** Two families only. **Sora** carries the display *and* the small uppercase labels
(at weight 600, since a geometric face needs more weight than a monospace at 10–13px);
**Barlow** carries body copy. The original IBM Plex Mono label layer was dropped — a
typewriter face fought with the geometric headline. This follows what the studios
you referenced actually do — Sony runs Futura PT, Disney Animation runs Brandon Grotesque
with Rockwell, Riot runs a custom sans with tight negative tracking. All of them use
geometric sans in title case. None uses the condensed all-caps display face that is the
portfolio-template default, which is why Bebas was dropped.

**Text content note.** Copy in `tools/build.py` uses literal Unicode (·, —, –, “ ”) rather
than HTML entities. Strings passed through `e()` get escaped, so an entity like `&middot;`
would become `&amp;middot;` and render as visible text. Only raw HTML templates use `&amp;`.

**Motion: the viewport language.** Hovering anything behaves like selecting an object in a
3D viewport — corner brackets snap inward, and hovering an image reveals a wireframe grid
over it. The hero sits inside a construction grid with framing reticles; panelled sections
carry a faint blueprint grid; section rules draw themselves in like construction lines.
Nothing translates or wiggles: the brackets are the signal. This extends the
Textured/Shaded/Wireframe scrubber into the whole site.

**The scrubber** is built from the real Textured/Shaded/Wireframe triplets. It anchors the
homepage and doubles as the Character Modeling hero.

**Above-the-fold media** is `loading="eager" fetchpriority="high"`; everything else is lazy.

Everything motion-related is disabled under `prefers-reduced-motion`.

Your original splatter logo is preserved at
`_masters/3ead9fec-206a-4bc0-bce1-e22533f26d34.png` if you would rather use the image
in the nav than the type lockup.
